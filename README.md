# ⚡ TERMINX — AI Knowledge Intelligence

TERMINX is a Retrieval-Augmented Generation (RAG) based knowledge intelligence system that uses semantic embeddings and FAISS vector search to retrieve relevant information from a knowledge base and generate grounded answers.

## 🚀 Features

- 🔎 Semantic search using sentence embeddings
- 🧠 Retrieval-Augmented Generation workflow
- ⚡ Fast vector similarity search using FAISS
- 📄 Upload and index custom PDF documents
- 📚 Built-in AI/ML knowledge base
- 🔍 Retrieval Trace showing relevant sources
- 🌑 Modern dark-themed Streamlit interface
